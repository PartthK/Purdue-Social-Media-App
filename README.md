# BoilerVibe: Your Purdue University Event Companion 🎉

BoilerVibe is a Flutter-based mobile application designed to centralize all Purdue University event information, making it easy for students to stay updated and connected. Built with Firebase as the backend, this app offers a seamless and responsive user experience.

## Features
- **Centralized Event Hub**: Find all Purdue events in one place, from club meetings to campus-wide activities.
- **Real-time Notifications**: Stay informed with Firebase Cloud Messaging, delivering instant updates and event reminders.
- **Responsive Design**: A polished UI ensures smooth performance across multiple device sizes and platforms.
- **User-friendly Interface**: Flutter’s widget system powers a sleek, intuitive interface for effortless navigation.

## Tech Stack
- **Frontend**: Flutter (Dart)
- **Backend**: Firebase (Authentication, Firestore, Cloud Messaging)
- **Design**: Figma for UI/UX planning

## Purpose
BoilerVibe was created to foster community engagement by making it easier for students to discover and participate in Purdue events. Whether you're a student organization or an event enthusiast, BoilerVibe is your go-to resource for staying connected on campus.

## Future Plans
- Adding event RSVPs and attendee tracking.
- Integration of a calendar view for easier scheduling.
- Enhanced search and filtering features for events.
